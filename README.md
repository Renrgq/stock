# 盘面雷达

一个面向 A 股盘后复盘的板块统计看板，直观展示市场概览、行业/概念板块涨跌、资金流向、板块强度和板块内龙头股。

## 已实现

- 三大指数、市场成交额、板块涨跌家数与市场温度概览
- 行业板块 / 概念板块切换
- 按涨跌幅、主力净流入、成交额排序
- 板块搜索与点击联动
- 龙头股综合强度列表与关注交互
- 主要指数快照与板块涨跌分布
- 桌面端、平板和手机端响应式布局

> 当前页面通过服务端接口读取东方财富公开行情。公开数据可能存在延时，不构成投资建议；上游暂时不可用时，页面会明确显示“演示回退”。

## 行情接口

站点将第三方请求统一封装在 `app/api/market/route.ts`，浏览器不会直接请求外部域名：

- `GET /api/market?type=industry`：行业板块、三大指数与市场概览
- `GET /api/market?type=concept`：概念板块、三大指数与市场概览
- `GET /api/market?board=BKxxxx`：指定板块的强势成分股

接口提供超时控制、实时/延时域名回退、30 秒缓存、参数校验和错误状态。页面支持手动刷新，并会根据行情时间显示最近更新时间。

## 数据结构

服务端统一输出以下结构，后续更换持牌数据源时无需重做页面：

- `marketSummary`：指数、成交额、板块涨跌家数和市场温度
- `sectors`：板块涨跌幅、成交额、主力净流入、成分股涨跌分布
- `leaders`：板块龙头股、价格、涨跌幅、换手率和入选理由
- `indices`：上证、深证成指与创业板指数快照

当前龙头股按板块成分股涨幅排序；板块强度由涨跌幅、板块涨跌家数和主力资金方向综合计算。
