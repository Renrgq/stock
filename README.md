# 盘面雷达

一个面向 A 股盘后复盘的板块统计看板，直观展示市场概览、行业/概念板块涨跌、资金流向、板块强度和板块内龙头股。

## 已实现

- 市场成交额、涨跌家数、涨跌停与赚钱效应概览
- 行业板块 / 概念板块切换
- 按涨跌幅、主力净流入、成交额排序
- 板块搜索与点击联动
- 龙头股综合强度列表与关注交互
- 大盘分时走势与个股涨跌分布
- 桌面端、平板和手机端响应式布局

> 当前页面使用明确标记的演示数据，不构成投资建议。真实行情可在 `app/page.tsx` 中将示例数组替换为服务端 API 返回值。

## 本地运行

```bash
pnpm install
pnpm dev
```

打开 `http://localhost:3000`。

## 生产构建

```bash
pnpm build
```

## 推荐的数据接入方式

生产环境建议使用持牌行情数据源或已获授权的行情 API，由服务端定时拉取并统一输出：

- `marketSummary`：指数、成交额、涨跌家数和涨跌停家数
- `sectors`：板块涨跌幅、成交额、主力净流入、成分股涨跌分布
- `leaders`：板块龙头股、价格、涨跌幅、换手率和入选理由
- `intraday`：指数或板块分时序列

龙头股评分建议由涨幅、成交额、换手率、板块贡献度、连板高度和市值权重等指标综合计算，并在页面中保留评分口径说明。
